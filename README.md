### 🚀 featured projects

**💷 [SpendSense](https://github.com/A00024033/spend-sense)** &nbsp;·&nbsp; *bank statement analyser*
Upload any UK bank CSV and every transaction is categorised automatically by a hybrid **rules + machine learning** engine that learns from your corrections. Evaluated honestly on merchants never seen in training: **96% accurate** when confident, with uncertain cases flagged for review instead of guessed.
`Python` `FastAPI` `scikit-learn` `SQLite` `React` `Docker` `GitHub Actions`

**🛂 [UK Student Visa AI Agent](https://github.com/A00024033/uk-student-visa-ai-agent)** &nbsp;·&nbsp; *explainable reasoning*
Conversational assistant that helps international students understand their work rights. Naive Bayes intent classification (written from scratch) plus a forward chaining rules engine, with cited confidence scores so every answer can be checked.
`Python` `NLP` `Naive Bayes` `Jupyter`

**🚕 [Rational Taxi Agent](https://github.com/A00024033/AI-agent)** &nbsp;·&nbsp; *search + probabilistic reasoning*
Taxi dispatch agent on a 7×7 grid model of London. BFS, DFS and A\* implemented from scratch and compared on evidence, then extended with Bayesian inference to handle passenger uncertainty and dispatch confidence.
`Python` `NumPy` `Matplotlib` `Jupyter`

**🍲 [Recipe Hub](https://github.com/A00024033/recipe-hub)** &nbsp;·&nbsp; *team of four*
Full stack recipe sharing platform with ingredient based search, ratings and a normalised MySQL schema. I owned security (BCrypt, CSRF tokens, Helmet) and containerised the whole stack with Docker Compose.
`Node.js` `Express` `MySQL` `Docker`
